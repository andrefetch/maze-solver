# Maze Solver

A Tkinter recursive maze generator and DFS solver, written in Python using the object-oriented programming paradigm.

![Maze Solver demo](assets/example2.gif)

## Usage

```bash
python main.py
```

## Tests

```bash
python -m unittest discover -s tests -v
```
