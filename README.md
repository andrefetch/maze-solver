# Maze Solver

A Tkinter maze generator and DFS solver, written for the [Boot.dev](https://www.boot.dev) "Build a Maze Solver" project.

## Usage

```bash
python main.py
```

## Tests

```bash
python -m unittest discover -s tests -v
```
